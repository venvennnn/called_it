# OBS browser source

1. In Called It, select a layout and click **Copy OBS link**. This creates/rotates a cryptographically random read-only credential. Keep the complete URL fragment private.
2. Add **Browser Source** in OBS. Paste the entire link and use **1920 × 1080**, with transparent background. Leave shutdown-when-hidden unchecked for a persistent source.
3. Position or crop the source using OBS transforms. The source places its card safely at the top-right with 45px padding; no game video is captured by Called It.
4. Compact/Locked show state-aware question, countdown, command, and locked mean. Forecast adds the frozen distribution. Results shows the confirmed outcome. Series shows the fixed five-round progress. Layouts follow the authoritative state; they cannot expose a result before confirmation.
5. Toggle Overlay visible off in the director to clear the source. Rotate the link in Settings to revoke all old overlay access; update the OBS URL afterward.

The fragment bootstraps into a signed HttpOnly restricted cookie and is removed from the address bar. The database stores its credential hash; subsequent refresh restores state. An overlay can read public snapshots but cannot publish, lock, resolve, export owner data, delete data, or disconnect Twitch. WebSocket access is role checked and invalidated on rotation. No celebration is replayed after refresh because the overlay uses a stable current state with no recurring celebration animation.

No live OBS process was available for this build. Chromium verified the transparent source route, credential bootstrap, refresh recovery, and rejection of an overlay mutation. Actual OBS compositing and reconnect should be confirmed by the owner before streaming. Preview gameplay and broadcaster illustrations are labeled Demo fixtures.
